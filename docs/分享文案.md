## 即刻 / 少数派 / V2EX

> **标题：写了个每天自动生成行业日报的流水线，重点是防 AI 编链接**
>
> 起因是每天翻二十几个半导体网站太累，想让机器替我做。
>
> 现在的流程：抓 20 个源 → 去重 → 并发校验每条原文链接 → 交给大模型写中文日报 →
> 链接白名单审计 → 推飞书。
>
> 两个设计我觉得值得单独说：
>
> **1. 链接校验放在 AI 前面。** 先验完再写，模型压根看不到死链。很多同类工具是
> 先让 AI 写、写完再验，结果一半条目因为死链被删，白花了 token。
>
> **2. 链接白名单审计。** 模型输出的每个 URL 都必须在候选列表里，不在的整块丢弃。
> 这是唯一能让 AI 生成的日报敢点开链接的做法。
>
> 飞书写入只用 `insert(index=0)`，代码里没有任何 delete 接口，跑一百次也不会覆盖旧内容。
> 没有 API key 也能跑（`--no-llm` 降级成列表排版）。
>
> 成本一天不到一分钱。代码 MIT，欢迎拿去改别的行业。
>
> github.com/<你的用户名>/semiconductor-news-digest
