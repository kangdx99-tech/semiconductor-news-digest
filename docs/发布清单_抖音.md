# 抖音发布清单 · 照着做就行

配套文件：
- 口播字幕：`docs/口播字幕_55秒.srt`（剪映/必剪直接导入，不用手打字幕）
- 口播全文：`docs/抖音口播文案.md`
- 各平台文案：`docs/分享文案.md`

---

## ⚠️ 先接受一个前提：抖音不给外链

视频、主页简介、评论区都**不能放可点击的 GitHub 链接**，写了大概率被限流或直接吞掉。
所以抖音的转化路径不是"点链接"，而是"留线索 → 私信/群里给"。
所有路径里，**最稳的是让观众自己去 GitHub 搜仓库名**（程序员群体完全够用）。

---

## 第一步：发布前必须先做完（没做完别发）

- [ ] **仓库上线 GitHub 并设为 public**，否则发出去也没人拿到代码
- [ ] **README 首屏能打**：打开仓库前 3 秒要能看懂"这是什么、能解决什么"。
      现在是成品日报示例 + 一句话定位，够用
- [ ] **仓库里加一张截图**：抖音观众看不到代码，GitHub 访客也一样。
      把成品日报截图存成 `docs/screenshot.png`，在 README 顶部引用
- [ ] **确认没有密钥泄露**：`git ls-files | grep -E "\.env$|^config\.yaml$"` 应该**没有输出**
- [ ] **自己 clone 到另一个目录**跑一遍 `python run.py --no-llm --dry-run`，
      确认别人照 README 能跑通（这一步最能暴露 README 的坑）

---

## 第二步：选形式（建议图文优先）

| 形式 | 适合 | 优势 |
|---|---|---|
| **图文（轮播 5-8 张）** | 技术类首选 | 代码截图能看清、能反复看、完播率高、不用露脸 |
| 短视频（45-60 秒） | 想涨粉/冲流量 | 传播上限高，但技术细节讲不清 |

**推荐组合**：先发一条图文讲"我做了个什么"（转化高），跑得动的话再补一条视频（拉流量）。

### 图文版 8 张图（按顺序）

1. **封面**：大字「让 AI 替你读 300 条芯片新闻」+ 小字「一天不到一分钱」
2. 成品日报截图（前 10 行，能看清「一句话总结」和 ①②③）
3. 终端运行截图（`python run.py` 那一屏，有 `[源] xxx 35 条` 那种）
4. **重点图**：`[丢弃] digitimes.com 网络错误` 那几行日志特写，配文字「打不开的直接删掉」
5. 提示词截图（`semidigest/prompt.py` 里"不许编链接"那几条规则）
6. 飞书文档截图：历史日报一路往下滚（证明"真的每天在跑"）
7. 架构图（README 里那个五步流程图，截图即可）
8. 结尾图：「GitHub 搜 semiconductor-news-digest」+「MIT 开源」

### 视频版：3 个镜头就够

1. 屏幕录制：终端跑起来（1~2 分钟真实过程，剪成 6 倍速，配字幕 6/7/8 句）
2. 屏幕录制：成品日报慢慢往下滚（配字幕 9 句）
3. 屏幕录制：`[丢弃]` 日志特写 + 提示词规则特写（配字幕 10/11/12 句）

**口播可以不用你自己录**：剪映的"文本朗读"选一个沉稳男声，把 `.srt` 里的字贴进去就行。

## 第三步：上传时的设置

**标题**（挑一个，别用问句，抖音不喜欢）
- 让 AI 替你读 300 条芯片新闻，一天不到一分钱
- AI 写日报会编链接，我加了道白名单校验
- 我把每天翻行业新闻这件事自动化了

**话题**：`#半导体 #芯片 #AI工具 #自动化 #效率工具 #程序员 #开源 #Python`
（前两个带行业标签，中间带工具标签——工具标签的流量池比行业标签大得多）

**封面文字**（大字，占屏 1/3 以上）：「AI 替我读 300 条新闻」

**其它**：
- 位置：不用加
- 合集：建一个「效率工具自动化」，后面几条都放进去，方便观众连着看
- 允许下载：**开**（技术内容被搬运反而帮你扩散）

## 第四步：引流路径（按可靠性排序）

**路径 1：口播/字幕念出来，让观众自己去 GitHub 搜**（最稳）
- 话术：「GitHub 搜 semiconductor-news-digest」
- 英文仓库名对中文观众有门槛，字幕上一定要**同时打出来**，光念没用

**路径 2：私信关键词自动回复**
- 抖音个人号可设「关键词自动回复」：关键词填「半导体」「日报」，自动回复里放仓库名
- 自动回复里**先只写文字版**：`github.com/你的用户名/semiconductor-news-digest`
  （去掉 https:// 更容易过）
- ⚠️ 发之前先用小号私信自己测一次，被拦就改成纯文字描述

**路径 3：粉丝群**
- 个人号可以建群，群里发文字版的仓库地址一般没问题
- 群名写「效率工具 / 自动化」，视频结尾说「进群发你」

**路径 4：跨平台承接**（转化最高的组合）
- 抖音简介写：「同名小红书/公众号，工具都在那儿」
- 小红书/公众号里放 GitHub 链接**没有限制**，所以真实路径是
  **抖音拉流量 → 小红书/公众号落地 → GitHub 拿代码**
- 这三个平台的文案 `docs/分享文案.md` 里都写好了

**关于置顶评论**：可以放，但**别放 http 链接**。写成
「GitHub 搜 semiconductor-news-digest，开源免费」——纯文字描述基本不会被拦。

## 第五步：发布后 24 小时

- 每一条评论都回，尤其是问「怎么用」「能换成 XX 行业吗」的——**这两类人就是你的精准用户**
- 有人问别的行业，直接答「改三个地方就行：源、关键词表、提示词，README 里写了」
- 发布 2 小时后看一眼数据：**完播率 < 25% 就是前 3 秒没抓住**，下次把钩子换成这个：
  「AI 写日报最大的问题是编链接，我找到办法治它了」
- 播放过 5000 就发第二条（同一个项目换角度：这次讲「为什么我不用现成的 RSS 阅读器」）

## 常见坑

1. **别在视频里念长网址** —— 观众记不住，还会被判定为导流。念仓库名，字幕打出来。
2. **别一上来讲半导体行业** —— 受众太窄。钩子打「AI 替我省时间/省钱」，工具标签的池子大 10 倍。
3. **别把仓库私有** —— 发了视频别人却看不到代码，评论会骂。
4. **别在评论里反复贴同一句话** —— 会被判刷屏，直接限流。要发就发一条然后置顶。
5. **别人问「会不会偷我 API key」** —— 提前在 README 里写清楚：密钥只从环境变量读，
   代码里零硬编码，`.gitignore` 已忽略 `.env`。这条被问到的概率很高。
